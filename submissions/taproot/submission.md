## Project summary

Taproot is a five-minute check-up for maths and science. A student names the chapter they are stuck on, or pastes the exact problem, and Taproot traces the trouble down the tree of earlier skills the chapter is built on to find the root gap and the misconception behind it, then repairs that skill and guides the student back up. It is for Class 8-12 students in Karnataka (State Board, PUC, CBSE), and for teachers, whose class dashboard shows which earlier skill most of the class is missing.

## Short answers

**1. What made you choose this problem?**

Maths and science are built in layers, so when a student cannot follow projectile motion the cause is often an older skill such as trigonometric ratios, not the chapter itself. Students respond by re-reading the chapter or watching more videos on it, which does not help because the gap is somewhere else, and school tests only say a student is weak in a chapter, never why. The gaps are real and compound: the national average maths score falls from 57% in Class 3 to 32% in Class 10 (National Achievement Survey 2021), and a randomised trial in Delhi found that teaching at each student's actual level raised maths scores by 0.37 standard deviations in 4.5 months. We chose this problem because it is common, it is invisible to the student, and a well-aimed fix is cheap once the real gap is found.

**2. Who is it for, and how would they use it in a normal week?**

A Class 8-12 student who is stuck on a chapter opens Taproot, picks one of five featured chapters or types any topic or problem, and answers about 14 one-tap questions, with an I'm not sure option so guesses do not distort the result. The report shows the root gap, the mix-up behind it (for example, swapping sine and cosine) and a confidence level; the student then does a short lesson, a worked example and three practice questions, and climbs back up skill by skill to the original chapter. Over a normal week they run a check-up when a new chapter feels shaky, repair one root gap in about ten minutes, and re-check after three days, since spaced practice helps it stick. A teacher signs in on Taproot's login page, makes a class and shares its six-character code, and students join from the same page with just that code (no student account or password); when students run their check-ups that week, the class dashboard ranks the root gaps across the class with the mix-ups behind them (for example, 4 of 8 students: trigonometric ratios, mostly swapping sine and cosine), so the teacher can plan one lesson on the missing skill instead of re-teaching the whole chapter. Joining a class is optional and sends only the outcome of each check-up, never a name or answers; everything else is free, needs no sign-up, and stays on the student's device.

**3. If you had another month, what would you build next?**

First, a pilot with real students in Karnataka classrooms, comparing Taproot's diagnoses with teachers' judgement, because our evidence so far (85% first-answer accuracy for the true root gap across 10,000 simulated students) is from simulation, not classrooms. Second, grow hand-checked coverage beyond the five featured chapters and add the Kannada language, since the app is English only today and custom topics rely on unreviewed AI-made skill trees. Third, build on the class dashboard we already have: let teachers assign a chapter to the class and track whether a root gap shrinks after they re-teach it, plus password reset and school-wide sign-in for teacher accounts. Fourth, reduce the effect of guessing with more question variants and short written-reasoning checks, and add offline support for low-connectivity schools.

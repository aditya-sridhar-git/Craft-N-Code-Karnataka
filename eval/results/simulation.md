# Simulation evaluation of the diagnostic engine

Generated by `npm run eval:sim` (seed 2026, 2,000 simulated students per topic, 5 topics). No real student data is used.

## How the simulation works

- Each simulated student gets 0 gaps (10%), 1 gap (60%) or 2 gaps (30%), placed on random skills in the topic's prerequisite tree (uniform over skills unless stated).
- A skill counts as known only if it isn't a gap and none of its prerequisites are gaps (a conjunctive, DINA-style model). The **true root gaps** are the gaps whose own prerequisites are all known.
- Answers are noisy: a known skill is answered wrongly 10% of the time (a slip). For an unknown skill the student picks "I'm not sure" 40% of the time and otherwise guesses among 4 options (25% lucky guesses).
- Taproot and the top-down walk stop after about 20 questions. "Test every skill" has no limit. "Chapter test only" asks 5 questions on the chapter itself, which is what a normal school test tells you.
- **Exact root match**: the reported root gaps are exactly the true ones. **First reported root is real**: the top suggestion is a true root (students with a gap). **Recall** and **precision** are per student, averaged.
